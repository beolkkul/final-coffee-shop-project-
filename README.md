## 📖 Overview
A responsive and interactive website designed for a fictional coffee shop. This project focuses on modern UI/UX, having a clean, earthy aesthetic to attract "customers". Sections include: About Us, Menu, Our Team, and Contact/Location details.

## 💻 Tech Stack
* **Front-End:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Libraries:** Swiper.js (for interactive carousels)
* **Layout & Styling:** CSS Flexbox, CSS Grid, Custom CSS Variables

## ✨ Features
* **Fully Responsive Design:** Adapts seamlessly to desktop, tablet, and mobile screens using comprehensive CSS media queries.
* **Interactive Mobile Menu:** Custom-built "hamburger" navigation that toggles on smaller screens.
* **Dynamic Content Slider:** Integrated Swiper.js to create an interactive, touch-friendly carousel for the "Our Team" section.
* **Maintainable Design System:** Utilized CSS `:root` variables to manage site-wide themes, colors, and typography.

## 🧠 What I Learned
Building this site helped me reinforce my understanding of responsive design and CSS architecture. I learned how to implement a "maintainable" design system using CSS variables, making it easy and quick to update the site's color palette. 

On the JavaScript side, I practiced DOM manipulation by building a functional mobile hamburger menu that toggles a specific class (`show-mobile-menu`) on the body element. Furthermore, I learned how to read documentation and integrate a third-party library by configuring **Swiper.js** to handle the responsive breakpoints and pagination for the team member slider.
